API 接入指南

对接 SOCKS5 开放平台。所有接口均采用 HTTPS 协议，数据格式为 JSON。

接口网关：https://web.lynli.me/api/v1

鉴权方式：请求头必须携带 Authorization: Bearer YOUR_API_KEY

严格权限隔离机制

本平台实行严格的接口隔离原则。账号接口的 Key（sk_tg_...）只能调用账号相关接口，节点（sk_jd_...）、接码（sk_sms_...）等其他模块的 Key 无法越权交叉调用。如强行跨模块请求，系统将直接返回 403 Forbidden。

通用基础接口

查询余额与商品数据不受模块隔离限制，任意有效 Key 均可调用。

GET /user/balance

查询当前 Key 所属账户的可用余额与冻结余额。

复制
{ "code": 200, "data": { "balance": 120.50, "frozen": 0.00 } }
GET /products

获取平台商品列表，支持通过参数拉取指定数量与分类。

请求参数 (Query)：

参数名类型必填描述
typestring否筛选商品类型：account / node / sms 等
limitint否指定调取数量（默认 20，最大 100）
pageint否页码（用于分页拉取）

请求示例 (获取前 5 个账号):

复制
curl -X GET "https://web.lynli.me/api/v1/products?type=account&limit=5" \ -H "Authorization: Bearer sk_tg_xxxxxx"

成功返回示例：

复制
{ "code": 200, "data": [ { "id": 3965, "name": "TG 飞机号", "price": 8.72, "stock": 1934 }, { "id": 1907, "name": "Gmail 老号", "price": 12.35, "stock": 0 } // ... 共 5 条 ] }
