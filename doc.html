01

快速接入

四步完成从账号到正式调用的准备。

01

注册并登录

注册成功后默认进入登录状态，控制台会同步账号、余额和 API Key 信息。

02

选择接口

在首页或控制台查看接口分类，点击进入对应文档查看接口地址和参数说明。

03

申请专属 Key

登录后在控制台查看或重置专属 API Key，正式调用时替换示例里的 demo key。

04

充值并调用

余额充足后即可发起正式调用，每次按接口展示的单次价格扣费。

02

账号与 API Key

正式调用前，把账号、接口分类和专属 Key 准备好。

A

平台账号

用于管理余额、充值、消费记录和专属 API Key。

ID

接口分类

账号、节点、接码等独立分类，调用对应 Key 即可。

Key

专属 Key

在控制台生成和维护，调用时放入请求头中。

⚠️ 不要把正式 Key 写进前端代码或公开仓库，服务端调用建议通过环境变量保存。

03

请求规范

统一网关地址，参数按接口详情页填写。

基础请求格式

GET https://web.lynli.me/api/v1/xxx

鉴权请求头

复制
Authorization: Bearer YOUR_API_KEY

cURL 示例

复制
curl -X GET "https://web.lynli.me/api/v1/user/balance" \ -H "Authorization: Bearer sk_live_xxxxxx"
  • Key：必填。控制台申请的专属 API Key。
  • 业务参数：按接口文档参数表填写，不同接口参数不同。
  • 返回格式：以接口详情页展示为准，通常为 JSON。
04

充值计费

价格、充值和记录按控制台统一管理。

单次价格

接口市场和详情页展示单次价格，正式调用按单次价格从余额扣除。

充值方式

控制台支持 USDT、支付宝充值，到账后可直接用于接口调用。

记录查询

收支明细和消费记录按页展示，便于核对余额变化与调用结果。

05

调试排查

常见错误可以先按下面几项快速定位。

401 Unauthorized

请求里没有传 API Key，或 Key 无效。

解决办法：登录控制台查看或重置 Key。

402 Insufficient Balance

账户余额不够支付本次调用。

解决办法：进入控制台完成充值后再试。

403 Forbidden

接口未申请或 IP 不在白名单。

解决办法：在控制台检查权限状态与全局白名单。

06

常见问题

把接入前最容易卡住的点放在这里。

注册后为什么要进入控制台？

控制台用于申请 Key、充值、查看余额和消费记录。正式接口调用依赖您的专属 Key。

接口参数在哪里看？

请点击下方的对应接口模块，进入详细文档查看具体的请求参数和示例。

调用失败会不会扣费？

通常只有成功返回业务数据的请求才会实际扣费，失败请求会返回对应的错误码且不扣费（接码业务的资金冻结机制除外）。
