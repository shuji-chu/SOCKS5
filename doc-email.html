发信时，您可以自由编辑前缀，例如用 `noreply@您的域名.com` 发送通知，或用 `vip@您的域名.com` 发送营销。

无论您是发注册验证码、密码找回、还是批量营销邮件，底层的高可用 SMTP 池都会保障送达率，不进垃圾箱。

03

单发/批量推送接口

POST /email/send

请求地址：https://web.lynli.me/api/v1/email/send

请求参数：

参数名必填说明
to是收件人邮箱
subject是邮件主题
html是邮件内容 (支持 HTML)
prefix否自定义前缀，如 noreply (不传则自动用默认)
domain否指定发件域名 (用于多域名用户)

cURL 示例：

复制
curl -X POST "https://web.lynli.me/api/v1/email/send" \ -H "Authorization: Bearer sk_email_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "to": "user@example.com", "subject": "您的注册验证码", "html": "

验证码: 888888，5分钟内有效。

", "prefix": "noreply" }'

成功返回：

复制
{ "code": 200, "msg": "已成功推送到发信队列", "data": { "message_id": "msg_99887766" } }
04

计费模式

按量计费 (发送成功才扣费)

发信时产生费用，若发送失败或退信，系统将自动返还额度。

域名绑定月租费

为确保通道不被恶意滥用，绑定独立域名需按年/月缴纳基础维护费，同时赠送额外发信额度。

05

发送记录查询

GET /email/logs

请求地址：https://web.lynli.me/api/v1/email/logs

查询您的历史发信记录，包含投递状态（成功/失败/进入垃圾箱）和退信原因。

返回示例：

复制
{ "code": 200, "data": [ { "message_id": "msg_99887766", "to": "user@example.com", "subject": "您的注册验证码", "status": "delivered", "send_time": "2026-10-22 15:30:00" } ] }
