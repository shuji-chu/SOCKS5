01

统一下单接口

用于服务器后端创建订单，并返回收银台链接。

POST /api/pay/create

请求地址：https://web.lynli.me/api/pay/create
提交格式：application/x-www-form-urlencoded

请求参数：

参数名必填说明
pid是商户 ID
type是支付方式：alipay 或 usdt
out_trade_no是商户订单号，需保持唯一
notify_url是服务器异步通知地址
return_url是支付后页面跳转地址
name是商品名称
money是订单金额，单位元，最多 2 位小数
param否业务扩展参数，支付后原样返回
clientip否用户 IP，不传则使用请求 IP
timestamp是10 位秒级时间戳
sign是RSA 签名（见下方说明）
sign_type是固定传 RSA

返回示例：

复制
{ "code": 0, "msg": "success", "trade_no": "202606130001000001", "out_trade_no": "M202606130001", "pay_type": "jump", "payurl": "https://web.lynli.me/cashier/202606130001000001", "qrcode": "https://web.lynli.me/cashier/202606130001000001", "timestamp": "1781270400", "sign_type": "RSA", "sign": "..." }

04

支付结果通知

订单支付成功后，平台会向商户传入的 notify_url 发起 GET 通知。

💡 通知签名说明：
通知签名跟随下单接口：V2接口使用 RSA；V1兼容接口使用 MD5。

通知参数：

字段名说明
pid商户 ID
trade_no平台订单号
out_trade_no商户订单号
type支付方式
name商品名称
money订单金额
trade_status支付成功固定为 TRADE_SUCCESS
param业务扩展参数
sign/sign_typeV2为RSA验签参数；V1为MD5验签参数
timestamp仅V2 RSA通知携带
⚠️ 处理规则：商户系统验签成功并确认订单状态后，必须返回纯文本 success，否则平台将判定通知失败并重复发送。
05

RSA 签名规则 (V2)

生成签名 (请求)

1. 取所有非空普通参数，排除 sign、sign_type 和数组参数。

2. 按参数名 ASCII 升序排序。

3. 拼接为 key=value&key2=value2 格式。

4. 使用商户私钥执行 SHA256WithRSA 签名，将结果进行 Base64 编码。

验证签名 (回调/返回)

接口返回、异步通知均使用平台私钥签名。商户系统按同样规则拼接待签名字符串，再用平台公钥验签。
