接码系统 API

请使用 sk_sms_ 开头的 API Key。请求头携带 X-API-Key。

端口描述 & 鉴权

网关地址：https://web.lynli.me/api/v1/sms

鉴权请求头：X-API-Key: sk_sms_xxxxxx

GET/me

查询账户余额。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/me" \ -H "X-API-Key: sk_sms_xxxxxx" // 返回 { "ok": true, "balance": "96.72" }

请求号码 (验证码接收)

POST/orders/create

指定服务和国家请求号码，冻结资金。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/orders/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"service_id": 510042, "country_name": "泰国"}'

获取短信 / 重新激活

POST/orders/{order_id}/sms

轮询获取验证码。等待状态可重复点击。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/orders/1001/sms" \ -H "X-API-Key: sk_sms_xxxxxx" // 成功返回 { "ok": true, "data": { "sms_code": "123456" } }

更改请求状态 / 释放号码

POST/orders/{order_id}/release

未收到短信时释放，全额退款。若已回码释放，按成功处理扣费。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/orders/1001/release" \ -H "X-API-Key: sk_sms_xxxxxx"

获取列表 & 记录

GET/countries & /services & /orders

获取国家、服务或历史短信记录。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/countries" \ -H "X-API-Key: sk_sms_xxxxxx"

获取可租借地区

GET/rent/tariffs

不传参数返回地区列表；传 `area_code` 返回该地可租月份和售价。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/rent/tariffs?area_code=US" \ -H "X-API-Key: sk_sms_xxxxxx"

租借号码

POST/rent/create

成功后立即扣费。20分钟内未收到短信可退款。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/rent/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"area_code": "US", "time": 1}'

获取租借订单

GET/rent/orders

支持 `tab=active` 或 `tab=expired`。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/rent/orders?tab=active" \ -H "X-API-Key: sk_sms_xxxxxx"

获取租借短信

POST/rent/{order_id}/sms

获取该租借号码的短信记录。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/rent/1001/sms" \ -H "X-API-Key: sk_sms_xxxxxx"

关闭租借号码

POST/rent/{order_id}/close

处于可关闭状态时关闭，并退回扣除余额。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/rent/1001/close" \ -H "X-API-Key: sk_sms_xxxxxx"

续租号码

POST/rent/{order_id}/renew

续租指定订单。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/rent/1001/renew" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"time": 1}'

通用短信接收 - 请求号码

POST/keyword-orders/create

监听包含特定关键词的短信。

复制
curl -X POST "https://web.lynli.me/api/v1/sms/keyword-orders/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"country": "中国", "keyword": "验证码"}'
