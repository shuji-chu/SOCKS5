API 接入指南

对接 SOCKS5 开放平台，获取卡密、节点、接码及支付能力。

1. 基础信息

接口网关：https://web.lynli.me/api/v1

鉴权方式：请求头携带 Authorization: Bearer YOUR_API_KEY

2. 通用错误码

  • 200 - 请求成功
  • 401 - API Key 无效或过期
  • 402 - 余额不足 (请前往控制台充值)
  • 403 - 接口未开通或 IP 不在白名单
  • 429 - 请求过于频繁

3. 账号接口 (卡密获取)

POST /order/account

curl -X POST "https://web.lynli.me/api/v1/order/account" \\
-H "Authorization: Bearer YOUR_API_KEY" \\
-H "Content-Type: application/json" \\
-d '{"product_id": 1, "quantity": 1}'
