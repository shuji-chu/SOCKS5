# SOSKS5 项目说明

## 项目定位
SOSKS5 是面向用户的数字商品、账号服务、节点服务、引流资源与业务 API 平台。

## 当前架构与上线说明
网站前端使用原生 HTML、JavaScript、Tailwind CSS，并通过 Hash 路由切换页面。GitHub Pages 仅托管静态文件，不能单独执行订单、支付回调、用户资料持久化或 AI 业务后端；这些功能需连接受保护的服务端 API 才能正式启用。

## 核心模块
- 首页：动态宇航员视觉、推广轮播、商品分类和教程入口。
- 账号商城：从现有商品接口读取商品、分类、库存和价格。
- 节点中心：从现有节点接口读取节点与连接信息。
- 引流广场：资源展示与用户投稿前端。
- 教程中心：登录、购买、节点、账号安全、接码与卡密使用指南。
- 开发者 API：面向客户和合作伙伴的业务接口文档。
- 支付：支付宝与 USDT 的 UI 入口可展示；真实收款、二维码核验、自动回调和自动交付必须由服务端支付网关完成，不能仅靠静态页面模拟。
