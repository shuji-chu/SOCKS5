接口与签名说明

接口说明及规范

协议规则：

  • 提交数据格式：application/x-www-form-urlencoded
  • 返回数据格式：JSON
  • 字符编码：UTF-8
  • V2签名算法：SHA256WithRSA

接入流程

  1. 登录商户后台，在个人资料的 API 信息里生成商户 RSA 密钥。
  2. 保存商户ID、平台公钥、商户私钥。
  3. 按签名规则生成请求签名，调用支付接口。
  4. 收到异步通知后验签，业务处理完成后返回纯文本 success。

签名规则

签名步骤

1. 取所有非空普通参数，排除 sign、sign_type 和数组参数，按参数名 ASCII 升序排序。

2. 排序后拼接为 key=value&key2=value2，使用商户私钥执行 SHA256WithRSA 签名，结果进行 Base64 编码。

验签步骤

接口返回、异步通知、同步跳转均使用平台私钥签名。商户系统按同样规则拼接待签名字符串，再用平台公钥验签。
