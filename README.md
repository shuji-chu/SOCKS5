## 一分钟部署

要求：Python 3。

```bash
git clone https://github.com/shuji-chu/SOCKS5.git
cd SOCKS5
python -m http.server 8080
```

浏览器打开 http://localhost:8080/src/ 。静态预览不包含后端能力；登录、注册、订单和支付需要部署真实 API。
