节点接口 API

底层基于 Lynli Panel 驱动，提供多格式订阅下发与节点调度能力。

Clash / V2Ray 高并发拉取 严格权限隔离
套餐与下单 支付与开通 获取订阅 权限隔离
01

获取套餐与创建订单

查询平台上架的所有节点套餐，并创建购买订单。

GET /user/plan/fetch

请求地址：https://web.lynli.me/api/v1/user/plan/fetch

返回示例：

复制
{ "code": 200, "data": [ { "id": 1, "name": "轻量版套餐", "traffic_gb": 100, "duration_days": 30, "price": 15.00 } ] }
POST /user/order/save

请求地址：https://web.lynli.me/api/v1/user/order/save

请求参数 (JSON)：

参数名必填说明
plan_id是套餐 ID
quantity否购买周期数（默认1）

返回示例：

复制
{ "code": 200, "msg": "订单创建成功", "data": { "order_no": "JD_169882300", "amount": 45.00 } }
02

调起支付

POST /user/order/pay

请求地址：https://web.lynli.me/api/v1/user/order/pay

参数名必填说明
order_no是上一步返回的订单号

返回示例：

复制
{ "code": 200, "data": { "type": "qrcode", "qrcode": "https://web.lynli.me/pay/qr/12345" } }
03

拉取节点订阅

GET /sub/{token}

请求地址：https://web.lynli.me/api/v1/sub/{token}

支持格式 (Query)：

格式请求方式返回结果
Clash不带参数 (默认)直接返回 YAML 文本流
V2Ray?target=v2ray返回 Base64 编码文本
sing-box?target=singbox返回 JSON 配置文件

请求示例：

复制
curl -X GET "https://web.lynli.me/api/v1/sub/abc123token?target=v2ray" \ -H "Authorization: Bearer sk_jd_xxxxxx"
04

严格权限隔离机制

⚠️ 跨模块调用将会被拦截：

本平台实行极其严格的模块隔离原则。节点接口必须使用 sk_jd_ 开头的专属 API Key 发起调用。

如果您使用账号（sk_tg_）、接码（sk_sms_）等无关模块的 Key 强行请求本接口，系统网关会直接返回 403 Forbidden。
