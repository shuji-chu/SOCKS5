功能简介

手机号二要素核验接口，直连三大运营商底层数据源，输入姓名和手机号，毫秒级返回校验结果。适用于绝大部分需要实名核验的互联网业务场景。

应用场景

  • APP/网站用户实名注册风控
  • 金融理财、借贷平台身份核验
  • 游戏防沉迷及账号安全保护
  • 电商平台收货人信息校验

请在请求 Header 中携带 Authorization: Bearer sk_cx_...

参数名类型必填描述
namestring是真实姓名
phonestring是手机号码（11位）
id_cardstring否身份证号（部分高级接口需要）

成功返回 (JSON)

{ "code": 200, "msg": "success", "data": { "status": "1", // 1为一致，0为不一致 "desc": "验证通过", "cost": 0.045 } }
