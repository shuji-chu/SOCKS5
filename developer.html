申请你的专属 API Key

使用晴天社区账号提交申请。密钥只在服务端成功签发后展示；页面不会本地生成或伪造 Key。

  • 一个应用对应独立密钥，便于权限与调用管理
  • 请勿将密钥写入公开网页、客户端源码或代码仓库
  • 如密钥泄露，应在开发者后台撤销并重新申请
API QUICK START

三步接入你的应用

将密钥保存在你自己的服务端环境变量中，再由服务端向晴天开放平台发起请求。

request.sh
curl "https://你的 API 域名/open/v1/products?page=1&size=20" \
  -H "X-API-Key: $SUNNY_API_KEY" \
  -H "Accept: application/json"

不要把 API Key 放在 URL 参数、浏览器代码或移动端安装包中。
