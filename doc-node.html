节点接口 API

VPN/代理节点接口

底层严格基于 Lynli Panel 驱动，支持多格式订阅下发。请使用 sk_jd_ 开头的 API Key 进行调用。

⚠️ 接口隔离：账号、接码等其他模块的 Key 调用此模块将返回 403。
GET /user/plan/fetch

获取可用的节点订阅套餐列表。对应 Lynli Panel 原生接口。

复制
curl -X GET "https://web.lynli.me/api/v1/user/plan/fetch" \ -H "Authorization: Bearer sk_jd_xxxxxx"

成功返回：

复制
{ "code": 200, "data": [ { "id": 1, "name": "轻量版", "traffic_gb": 100, "duration_days": 30, "price": 15.00 } ] }
POST /user/order/save

创建节点套餐购买订单。

参数名类型必填描述
plan_idint是套餐 ID
quantityint否购买周期数（默认1）
复制
curl -X POST "https://web.lynli.me/api/v1/user/order/save" \ -H "Authorization: Bearer sk_jd_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "plan_id": 1, "quantity": 1 }'

返回示例：

复制
{ "code": 200, "data": { "order_no": "JD_169882300", "amount": 15.00 } }
POST /user/order/pay

调起支付接口，获取支付链接或二维码。

参数名类型必填描述
order_nostring是上一步返回的订单号
复制
{ "code": 200, "data": { "type": "qrcode", "qrcode": "https://web.lynli.me/pay/qr/12345" } }
GET /sub/{token}

拉取节点配置，底层支持三种主流客户端格式。

格式请求方式返回结果
Clash YAML/sub/{token}直接返回 YAML 文本流
V2Ray/sub/{token}?target=v2ray返回 Base64 编码文本
sing-box/sub/{token}?target=singbox返回 JSON 配置文件

请求示例：

复制
curl -X GET "https://web.lynli.me/api/v1/sub/abc123token?target=v2ray"
