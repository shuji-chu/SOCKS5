节点接口 API

VPN/代理节点接口

本模块提供节点订阅拉取、套餐购买及订单创建能力。请使用 sk_jd_ 开头的 API Key 进行调用。

⚠️ 节点业务底层由 Lynli Panel 驱动，支持 Clash / V2Ray / sing-box 多格式输出。账号、接码等其他模块的 Key 无法调用此模块。
GET /user/plan/fetch

获取可用的节点订阅套餐列表（含流量、时长、价格）。

请求示例：

复制
curl -X GET "https://web.lynli.me/api/v1/user/plan/fetch" \ -H "Authorization: Bearer sk_jd_xxxxxx"

成功返回示例：

复制
{ "code": 200, "data": [ { "id": 1, "name": "轻量版套餐", "traffic_gb": 100, "duration_days": 30, "price": 15.00 }, { "id": 2, "name": "专业版套餐", "traffic_gb": 500, "duration_days": 30, "price": 45.00 } ] }
POST /user/order/save

创建节点套餐购买订单，随后调用支付接口完成扣费。

请求参数 (JSON Body)：

参数名类型必填描述
plan_idint是套餐 ID
quantityint否购买周期数（默认1，如买2个月传2）

请求示例：

复制
curl -X POST "https://web.lynli.me/api/v1/user/order/save" \ -H "Authorization: Bearer sk_jd_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "plan_id": 2, "quantity": 1 }'

返回示例 (获取订单号)：

复制
{ "code": 200, "msg": "订单创建成功", "data": { "order_no": "JD_169882300", "amount": 45.00 } }
GET /sub/{token}

通过用户的订阅 Token 获取实际节点配置。支持多客户端格式。

请求参数 (Query)：

参数名类型必填描述
tokenstring是用户订阅专属 Token (URL路径中)
targetstring否输出格式：
留空默认 Clash YAML
传 v2ray 返回 base64
传 singbox 返回 JSON

请求示例：

复制
# 获取 Clash 配置 curl -X GET "https://web.lynli.me/api/v1/sub/abc123token" # 获取 V2Ray Base64 格式 curl -X GET "https://web.lynli.me/api/v1/sub/abc123token?target=v2ray" # 获取 sing-box JSON curl -X GET "https://web.lynli.me/api/v1/sub/abc123token?target=singbox"

返回结果：

直接返回对应格式的文本文件流（可直接导入客户端）。
