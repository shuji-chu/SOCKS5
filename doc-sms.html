接码系统 API

全面支持动态验证码接收、长期号码租借以及关键词监听。请使用 sk_sms_ 开头的 API Key 进行调用。

接口网关：https://web.lynli.me/api/v1/sms

鉴权方式：在请求头中携带 X-API-Key: sk_sms_xxxxxx

⚠️ 资金安全机制：请求号码时先冻结对应金额。成功获取到短信验证码后才会实际扣费；若未收到或主动释放，资金将全额退回。
GET/countries

获取国家列表

复制
{ "ok": true, "data": [{"code": "US", "name": "美国"}] }
GET/services

获取服务项目(可传country过滤)

复制
{ "ok": true, "data": [{"id": 510042, "name": "WeChat"}] }
POST/orders/create

请求分配号码。调用时冻结资金。

参数名类型必填描述
service_idint是服务ID (如 510042)
country_namestring是国家名称 (如 泰国)
复制
curl -X POST "https://web.lynli.me/api/v1/sms/orders/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"service_id": 510042, "country_name": "泰国"}'
POST/orders/{order_id}/sms

轮询获取短信。等待状态可重复请求；成功返回短信时才扣费。

复制
{ "ok": true, "data": { "sms_code": "123456", "full_text": "Your code is 123456" } }
POST/orders/{order_id}/release

未收到短信时释放号码。若释放前已回码，将按成功处理并扣费，否则全额退款。

复制
{ "ok": true, "msg": "号码已释放" }
GET/orders

获取历史短信订单记录。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/orders" \ -H "X-API-Key: sk_sms_xxxxxx"
GET/rent/tariffs

不传参数返回地区列表；传 area_code 返回该地区可租月份和售价。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/rent/tariffs?area_code=US" \ -H "X-API-Key: sk_sms_xxxxxx"
POST/rent/create

租借成功后立即扣费。开始 20 分钟内未收到短信且处于可关闭状态时，可退款。

参数名类型必填描述
area_codestring是地区代码 (如 US)
timeint是租借月数
复制
curl -X POST "https://web.lynli.me/api/v1/sms/rent/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"area_code": "US", "time": 1}'
GET/rent/orders

获取订单列表，支持传参 tab=active 或 tab=expired。

POST/rent/{order_id}/sms

获取该租借号码的短信记录。

POST/rent/{order_id}/close

处于可关闭状态时关闭号码，成功后平台自动退回该订单扣除的余额。

POST/rent/{order_id}/renew

续租号码（可先调 GET /renew-options 查询续租价格）。

POST/keyword-orders/create

不指定具体服务，而是分配一个号码并监听包含特定关键词的短信。

参数名类型必填描述
countrystring是国家名称 (如 中国)
keywordstring是短信关键词 (如 验证码)
复制
curl -X POST "https://web.lynli.me/api/v1/sms/keyword-orders/create" \ -H "X-API-Key: sk_sms_xxxxxx" \ -d '{"country": "中国", "keyword": "验证码"}'

获取短信与释放号码接口，复用上方 /orders/{order_id}/sms 和 /orders/{order_id}/release 接口即可。
