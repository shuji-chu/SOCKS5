# S5 项目说明

S5 提供数字商品展示、账号商城、节点中心、引流资源、教程中心和面向客户/合作伙伴的业务 API 文档。

## 上线架构说明
前端使用原生 HTML、JavaScript、Tailwind CSS 与 Hash 路由。GitHub Pages 只能托管静态文件；订单、用户资料、真实支付、二维码回调、自动交付和 AI 业务操作必须连接受保护的服务端 API，不能仅靠前端假装完成。

## 主要模块
- 账号商城：读取现有商品接口。
- 节点中心：读取现有节点接口。
- 引流广场：资源发现与投稿前端。
- 教程中心：注册登录、购买交付、节点配置、账号安全、接码与卡密指南。
- 开发者 API：面向外部客户和合作伙伴的业务接口文档。
- 支付：支付宝与 USDT；真实到账核验、签名回调及自动交付需由服务端实现。
