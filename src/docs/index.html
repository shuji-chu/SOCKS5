快速开始

客户网站使用同源 API 前缀 /api。如果分销商服务端调用独立 API 域名，请以运营方提供的正式地址替换示例。

curl -sS 'https://YOUR-DOMAIN/api/products' \
  -H 'Accept: application/json'
这是接入模板。正式生产环境的 API 域名、签名规则、配额和字段必须由服务端配置并公布。

GET /api/products · 商品列表

读取商品名称、分类、价格、可售库存与保修期限。下单时应使用服务端返回的商品 ID。

GET /api/products
Accept: application/json

// 示例结构（非保证真实字段）
{
  "ok": true,
  "data": [
    {
      "id": 1001,
      "title": "套餐名称",
      "price": 1.00,
      "stock": 10,
      "category": "账号"
    }
  ]
}

库存与节点查询

当前客户前端使用 GET /api/products 与 GET /api/nodes。如需给分销商开放独立库存 API，建议只返回可售数量和公开规格，严禁返回未售账号的明文凭据。

GET /api/nodes
Accept: application/json

POST /api/orders · 创建订单

下单请求应由服务端重新计算价格、校验库存和用户权限，并实现幂等处理。现有前端的订单参数请与后端实际实现保持一致。

POST /api/orders
Content-Type: application/json
Authorization: Bearer USER_OR_PARTNER_TOKEN

{
  "items": [{"product_id": 1001, "quantity": 1}],
  "payment_method": "alipay"
}

支付方式可按后端实际支持情况扩展为支付宝、微信支付或 USDT TRC20。

鉴权与错误码

Authorization: Bearer YOUR_PARTNER_TOKEN

200 请求成功
400 参数错误
401 Token 缺失或无效
403 权限不足
404 商品或订单不存在
409 库存不足 / 重复请求
429 请求过于频繁
500 服务端错误

建议每个分销商使用独立 Token，设置限流、权限范围、配额、轮换与审计日志。公开商品列表是否免鉴权以服务端策略为准。

支付回调与自动交付

支付回调必须在服务端验签，核对金额、币种、商户订单号与交易号；使用数据库事务和幂等键防止重复发货。只有确认到账后才发放商品。

浏览器跳转、前端提示和用户截图均不能作为到账凭证。USDT TRC20 应核验交易、目标地址、金额、确认数与订单绑定关系。

AI 在线客服

网站悬浮客服向同源 POST /api/ai/chat 发送消息，预期读取 reply 或 answer 字段。请在后端连接智谱 AI 或自有模型服务，并把 API Key 保存在服务端环境变量。

POST /api/ai/chat
Content-Type: application/json

{
  "message": "如何配置节点？",
  "context": "SOSKS5 客户网站客服"
}
