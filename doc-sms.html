接码接口 API

实时验证码接码接口

全自动取号、监听短信、成功扣费。请使用 sk_sms_ 开头的 API Key 进行调用。

资金机制说明：调用取号接口时，系统将冻结对应金额。收到验证码后实际扣费；超时未收到（默认15分钟）或主动释放，则自动解冻退款。
GET /sms/products

获取支持接码的 APP 项目（如 Telegram、WhatsApp）及对应可用国家列表。

复制
curl -X GET "https://web.lynli.me/api/v1/sms/products" \ -H "Authorization: Bearer sk_sms_xxxxxx"

返回示例：

复制
{ "code": 200, "data": [ { "service_code": "tg", "service_name": "Telegram", "price": 1.50, "countries": [ { "id": 1, "name": "美国", "code": "US" }, { "id": 2, "name": "英国", "code": "UK" } ] } ] }
POST /sms/get

发起取号请求。调用后，用户账户将冻结对应金额，并返回一个手机号。

参数名类型必填描述
service_codestring是服务标识（如 tg）
country_idint是国家 ID（可选填 0 代表任意国家）
复制
curl -X POST "https://web.lynli.me/api/v1/sms/get" \ -H "Authorization: Bearer sk_sms_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "service_code": "tg", "country_id": 1 }'

成功返回 (生成 session_id)：

复制
{ "code": 200, "msg": "取号成功，请开始监听", "data": { "session_id": "SESS_998877", "phone": "+12025550143", "expire_in": 900 } }
GET /sms/check

轮询获取短信内容。建议每 3-5 秒请求一次。收到短信后自动扣除冻结资金。

参数名类型必填描述
session_idstring是取号接口返回的会话 ID
复制
curl -X GET "https://web.lynli.me/api/v1/sms/check?session_id=SESS_998877" \ -H "Authorization: Bearer sk_sms_xxxxxx"

状态 1：等待中（继续轮询）

复制
{ "code": 404, "msg": "等待验证码中..." }

状态 2：收到验证码

复制
{ "code": 200, "data": { "sms_code": "458921", "full_text": "Your Telegram code is 458921" } }
POST /sms/release

主动放弃接码。若资金仍处于冻结状态，将立即全额退还至用户余额。

参数名类型必填描述
session_idstring是需要释放的会话 ID
复制
{ "code": 200, "msg": "已释放号码，冻结资金已退回" }
