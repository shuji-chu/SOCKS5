API 接入指南

对接 SOCKS5 开放平台，获取卡密、节点、接码及支付能力。所有接口均采用 HTTPS 协议，数据格式为 JSON。

接口网关：https://web.lynli.me/api/v1

鉴权方式：所有请求头必须携带您的专属密钥：
Authorization: Bearer YOUR_API_KEY

对接业务前，请先通过以下接口获取您的账户余额以及商品信息。

GET /user/balance

查询当前 API Key 所属账户的可用余额与冻结余额。

请求示例 (cURL)：

复制
curl -X GET "https://web.lynli.me/api/v1/user/balance" -H "Authorization: Bearer sk_tg_xxxxxx"

成功返回示例：

复制
{ "code": 200, "msg": "success", "data": { "balance": 120.50, "frozen": 0.00, "currency": "CNY" } }
GET /products

获取平台所有商品的 ID、名称、分类及实时价格。下游系统可据此动态渲染商品展示。

请求参数 (Query)：

参数名类型必填描述
typestring否商品类型，如 account / sms / domain
categorystring否商品分类，如 Telegram / Gmail

成功返回示例：

复制
{ "code": 200, "msg": "success", "data": [ { "id": 3965, "name": "[货号3965] Telegram飞机号/电报 | +1美国电话", "type": "account", "category": "Telegram", "price": 8.72, "stock": 1934 }, { "id": 1907, "name": "Google Gmail 账号 | 2006-2019年老号", "type": "account", "category": "Gmail", "price": 12.35, "stock": 0 } ] }

通过 API 自动购买 TG、Gmail 等成品账号。支付成功后，系统会直接返回卡密内容（如：账号----密码----辅助邮箱）。

POST /account/buy

请求参数 (JSON Body)：

参数名类型必填描述
product_idint是商品 ID，可在商品详情页或控制台获取
quantityint是购买数量（需小于等于实时库存）

请求示例 (cURL)：

复制
curl -X POST "https://web.lynli.me/api/v1/account/buy" \ -H "Authorization: Bearer sk_tg_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "product_id": 3965, "quantity": 1 }'

成功返回示例：

复制
{ "code": 200, "msg": "购买成功", "data": { "order_no": "ORD20261022X8899", "amount": 8.72, "cards": [ "13800138000|https://sms.lynli.me/api/get?token=abc123" ] } }
GET /account/stock

查询指定商品的实时库存数量，防止下游超卖。

参数名类型必填描述
product_idint是查询的商品 ID

成功返回示例：

复制
{ "code": 200, "data": { "product_id": 3965, "stock": 1934, "price": 8.72 } }
