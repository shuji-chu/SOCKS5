01

快速接入

四步完成从账号到正式调用的准备。

01

注册并登录

注册成功后默认进入登录状态，控制台会同步账号、余额和 API Key 信息。

02

选择查询接口

在接口市场按分类筛选接口，进入详情页查看接口 ID 和参数说明。

03

申请专属 Key

登录后在控制台查看或重置专属 API Key，正式调用时替换示例里的 demo key。

04

充值并调用

余额充足后即可发起正式调用，每次按接口展示的单次价格扣费。

02

账号与 API Key

正式调用前，把账号、接口 ID 和专属 Key 准备好。

A

平台账号

用于管理余额、充值、消费记录和专属 API Key。

ID

接口 ID

每个接口详情页都会展示，调用时使用参数 id 传入。

Key

专属 Key

在控制台生成和维护，调用时使用参数 key 传入。

⚠️ 不要把正式 Key 写进前端代码或公开仓库，服务端调用建议通过环境变量保存。

03

请求规范

统一网关地址，参数按接口详情页填写。

基础请求格式

GET https://web.lynli.me/api/v1/query

cURL 示例

复制
curl -G "https://web.lynli.me/api/v1/query" \ --data-urlencode "id=接口ID" \ --data-urlencode "key=sk_cx_你的API_KEY" \ --data-urlencode "keyword=示例参数"
  • id：必填。接口详情页展示的接口 ID。
  • key：必填。控制台申请的专属 sk_cx_ 开头的 API Key。
  • 业务参数：按接口详情页参数表填写，不同接口参数不同（如二要素需传姓名和身份证）。
  • 返回格式：以接口详情页展示为准，通常为 JSON。
04

充值计费

价格、充值和记录按控制台统一管理。

单次价格

接口市场和详情页展示单次价格，正式调用按单次价格从余额扣除。

充值方式

控制台支持 USDT、支付宝充值，到账后可直接用于接口调用。

记录查询

收支明细和消费记录按页展示，便于核对余额变化与调用结果。

05

调试排查

常见错误可以先按下面几项快速定位。

缺少 id

请求里没有传接口 ID，或接口 ID 填错。

解决办法：回到接口详情页复制正确的接口 ID。

缺少 key

请求里没有传专属 API Key。

解决办法：登录控制台查看或申请 sk_cx_ 开头的 Key。

余额不足

账户余额不够支付本次调用。

解决办法：进入控制台完成充值后再试。

接口维护

接口当前处于维护或平台服务临时不可用。

解决办法：稍后重试，或联系平台客服。

06

常见问题

把接入前最容易卡住的点放在这里。

注册后为什么要进入控制台？

控制台用于申请 Key、充值、查看余额和消费记录。正式接口调用依赖您的专属 Key。

接口参数在哪里看？

请在 API 市场点击具体的接口进入详情页，里面详细列出了该接口所有的请求字段与返回示例。

调用失败会不会扣费？

通常只有成功返回业务数据的请求才会实际扣费。如果是缺少参数、余额不足或网络异常等失败情况，系统不会扣费。
