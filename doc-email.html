01

快速接入流程

三步完成配置，即刻开始海量发信。

01

获取网关 Key

在控制台申请 `sk_email_` 开头的专属密钥。

02

提交域名核实（可选）

在控制台绑定您的域名。您只需配置 CNAME，系统核实无误后自动绑定生效。

03

开始调用 API 代发

调用发信接口，传入您自定义的前缀（如 `noreply`），平台将为您全托管发送。

02

核心概念与代发机制

1. 专属域名绑定 & 自动核实

您可以将您的品牌域名（如 `@yourdomain.com`）绑定到本平台。系统会给出解析记录，APP 或网站确认归属后，自动绑定发送，无需人工干预。

2. 全托管代发 (无需自建)

您不需要懂任何邮件服务器配置（SPF/DKIM 等）。只要绑定域名，我们底层的高可用 SMTP 池会全权代理发送，极大提升送达率。

3. 自定义前缀编辑

支持 API 动态传入 `from_name` 和 `from_prefix`。例如，您可以自定义发出 `admin@yourdomain.com` 或 `vip@yourdomain.com`。

03

发送邮件接口

POST /email/send

请求地址：https://web.lynli.me/api/v1/email/send
提交格式：application/json

请求参数：

参数名必填说明
to是收件人邮箱地址
subject是邮件主题
html是HTML 格式的邮件内容
from_prefix否自定义前缀 (如 noreply, admin)，不传则使用默认
from_name否发件人显示名称 (如 SOCKS5 官方)

cURL 示例：

复制
curl -X POST "https://web.lynli.me/api/v1/email/send" \ -H "Authorization: Bearer sk_email_xxxxxx" \ -H "Content-Type: application/json" \ -d '{ "to": "customer@gmail.com", "subject": "您的验证码", "html": "

您的验证码是 8888

", "from_prefix": "security", "from_name": "安全中心" }'

返回示例：

复制
{ "code": 200, "msg": "发送任务已提交", "data": { "message_id": "msg_99887766", "status": "queued" } }

计费规则

发送计费

采用按量计费模式，发送成功才扣除额度。余额可直接用于平台内充值。

域名绑定月租

为防止恶意发信，绑定专属自定义域名需缴纳固定的月租费（如 50元/月）。绑定后赠送测试额度。

高可用通道保障

平台底层采用多 IP 轮询与海外优质 SMTP 池，保障极高的送达率。遇到退信不扣费。

05

调试排查

域名未核实通过

请检查您域名的 TXT / CNAME 解析记录是否正确配置。核实过程通常需要 5-10 分钟生效。

发件权限受限

可能是账户余额不足，或者触发了防滥发风控（如单日发送量突增，收件人退信率过高）。

进入垃圾箱

建议邮件内容尽量规避敏感营销词汇，提供退订链接。也可以联系客服申请切换到高信誉 IP 池通道。
