API 接入指南

对接 SOCKS5 开放平台，获取卡密、节点、接码及支付能力。

接口网关：https://web.lynli.me/api/v1

鉴权方式：所有请求头必须携带 Authorization: Bearer YOUR_API_KEY

通用错误码

200 - 请求成功

401 - API Key 无效或失效（请前往控制台核对）

402 - 余额不足，请充值

403 - 接口权限未开通或 IP 不在白名单

429 - 请求过于频繁（触发限流）

1. 账号接口

静态卡密分发

通过 API 自动购买 TG、Gmail 等成品账号。支付成功后，系统会直接返回卡密内容（如：账号----密码----辅助邮箱）。

POST /account/buy

请求参数 (JSON Body)：

product_id必填 (int) - 商品 ID，可在控制台商品列表查看
quantity必填 (int) - 购买数量（需库存充足）

请求示例 (cURL)：

curl -X POST "https://web.lynli.me/api/v1/account/buy" \ -H "Authorization: Bearer sk_tg_xxxxxx" \ -H "Content-Type: application/json" \ -d '{"product_id": 3965, "quantity": 1}'

成功返回示例：

{ "code": 200, "msg": "购买成功", "data": { "order_no": "ORD20261022X8899", "amount": 8.72, "cards": [ "13800138000|https://sms.lynli.me/api/get?token=abc123" ] } }
GET /account/stock?product_id=3965

查询指定商品的实时库存数量，防止超卖。

{ "code": 200, "data": { "product_id": 3965, "stock": 1934, "price": 8.72 } }
