对接说明

请将您的 API Key 放在 HTTP 请求头中：Authorization: Bearer YOUR_API_KEY

1. 获取账户余额

接口：GET /api/v1/user/balance

curl -X GET "https://web.lynli.me/api/v1/user/balance" \\
-H "Authorization: Bearer YOUR_API_KEY"

2. 购买卡密 (静态)

接口：POST /api/v1/order/static

curl -X POST "https://web.lynli.me/api/v1/order/static" \\
-H "Authorization: Bearer YOUR_API_KEY" \\
-H "Content-Type: application/json" \\
-d '{"product_id": 1, "quantity": 1}'
