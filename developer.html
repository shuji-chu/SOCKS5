API 接入极简指南

统一鉴权，读取大号商账号与全球节点数据

不用自己搭建复杂供应链，用晴天 API，快速接入全球节点与大号商账号。
把密钥安全保存在自己的服务端，即可读取节点地区、协议能力与大号商账号 SKU；你专注产品体验，供应链数据由晴天提供。

STEP 01 · 申请密钥

登录后提交应用名称与用途，服务端签发后复制 API Key，只保存在服务端环境变量。

STEP 02 · Header 鉴权

每次请求携带 X-API-Key。不要把密钥写进网页前端、公开仓库或客户端安装包。

STEP 03 · 处理 JSON

检查 HTTP 状态码与 success 字段；对超时、限流和重复请求做好重试与幂等处理。
